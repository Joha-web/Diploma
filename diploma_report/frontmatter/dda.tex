\chapter{Designations and Abbreviations}
\begin{SingleSpace}

The following designations and abbreviations are used in this work:\par\bigskip

\sloppy
\begin{description}[style=multiline,leftmargin=3cm,labelwidth=2.8cm]
  \item[API]      Application Programming Interface
  \item[AST]      Abstract Syntax Tree
  \item[BOLA]     Broken Object-Level Authorization
  \item[CIDR]     Classless Inter-Domain Routing
  \item[CLI]      Command-Line Interface
  \item[CORS]     Cross-Origin Resource Sharing
  \item[CSP]      Content Security Policy
  \item[CVE]      Common Vulnerabilities and Exposures
  \item[CVSS]     Common Vulnerability Scoring System
  \item[CWE]      Common Weakness Enumeration
  \item[DAST]     Dynamic Application Security Testing
  \item[DNS]      Domain Name System
  \item[GraphQL]  Graph Query Language
  \item[HSTS]     HTTP Strict Transport Security
  \item[HTML]     HyperText Markup Language
  \item[HTTP]     HyperText Transfer Protocol
  \item[HTTPS]    HyperText Transfer Protocol Secure
  \item[IDOR]     Insecure Direct Object Reference
  \item[JS]       JavaScript
  \item[JSON]     JavaScript Object Notation
  \item[JWT]      JSON Web Token
  \item[LLM]      Large Language Model
  \item[OAST]     Out-of-Band Application Security Testing
  \item[OAuth]    Open Authorization
  \item[OOB]      Out-of-Band
  \item[OSINT]    Open-Source Intelligence
  \item[OWASP]    Open Worldwide Application Security Project
  \item[REST]     Representational State Transfer
  \item[SAST]     Static Application Security Testing
  \item[SARIF]    Static Analysis Results Interchange Format
  \item[SIEM]     Security Information and Event Management
  \item[SPA]      Single-Page Application
  \item[SQL]      Structured Query Language
  \item[SQLi]     SQL Injection
  \item[SSL]      Secure Sockets Layer
  \item[SSRF]     Server-Side Request Forgery
  \item[SSTI]     Server-Side Template Injection
  \item[TLS]      Transport Layer Security
  \item[URL]      Uniform Resource Locator
  \item[UUID]     Universally Unique Identifier
  \item[WAF]      Web Application Firewall
  \item[XML]      eXtensible Markup Language
  \item[XSS]      Cross-Site Scripting
  \item[XXE]      XML External Entity
  \item[YAML]     YAML Ain't Markup Language
\end{description}
\end{SingleSpace}
