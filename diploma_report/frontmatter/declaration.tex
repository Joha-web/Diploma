\chapter{Declaration of Academic Integrity}
\begin{SingleSpace}
I, \textsc{Mavlanov Shakhrukh}, student of Astana IT University, group CS-2304, hereby declare that this diploma project, entitled
\begin{quote}
\textit{Development of a Method for External Penetration Testing of a Web Application for Vulnerabilities},
\end{quote}
is my own original work carried out under the supervision of PhD Amirova Akzhibek.

I further declare that:
\begin{enumerate}
  \item All sources of information used in this work are cited and referenced in accordance with the bibliographic requirements of Astana IT University (document DP-AITU-19).
  \item All third-party software components used by the ReconX framework --- Python libraries listed in \texttt{requirements.txt} and external command-line tools listed in Chapter~3 --- are used in accordance with their respective open-source licenses and are acknowledged in the Technology Stack section and in the bibliography.
  \item The Python source code of the ReconX framework, including \texttt{main.py}, the modules under \texttt{modules/} (reconnaissance, configuration audit, active probes, finding registry, correlator, asset risk, AI report), the reporting layer under \texttt{reporting/}, and the HTML report template under \texttt{templates/}, was written by me independently. Any code segments adapted from official documentation or open-source examples are identified in the source code comments.
  \item The experimental work described in Chapter~3 was performed under one of the following two authorization regimes:
  \begin{enumerate}
    \item \textbf{Deliberately vulnerable laboratory targets} (\textit{OWASP Juice Shop}), for which security testing is unconditionally authorized by the project's licence and by long-standing community practice. The Juice Shop quantitative results reported in Chapter~3 are presented as illustrative values from a representative laboratory run.
    \item \textbf{One real-world target} --- the \texttt{miras.app} academic management system --- which was scanned with the prior written authorization of the system's owner, within an agreed scope and time window. No payload that could damage or alter production data was issued, the framework was launched in its \texttt{bug\_bounty} profile (\texttt{allow\_write: false}), and the audit log of every issued HTTP request is preserved with the scan results.
  \end{enumerate}
  \item No other external production system was scanned during the preparation of this work. Scans of other educational and commercial domains in Kazakhstan that appear in the local \texttt{output/} directory of the repository were performed for the author's own learning before the scope of this thesis was finalised and are \emph{not} referenced as evidence anywhere in this document.
  \item This work has not been submitted, in whole or in part, for any other academic qualification or assessment at this or any other institution.
  \item I understand that violation of the Academic Integrity Policy of Astana IT University (document DP-AITU-05) may result in disqualification of this work.
\end{enumerate}
