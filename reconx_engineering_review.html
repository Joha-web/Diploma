Confirmed Bugs §2

modules/ai_report.py · _ollama_generate() · line ~130

MEDIUM Dead assignment — response parsed twice, first result discarded

The response JSON is parsed and assigned to text, then immediately overwritten on the next line. The first parse result is thrown away. This is a latent bug: if the two resp.json() calls ever return different objects (e.g. streaming response), the first value is silently lost.

CURRENT CODE

Fix: delete the first assignment entirely. The second line is correct.

Module Spec: cors_checker.py §7

Runs after ssl_checker in group 4. Pure Python, no new binaries. Add cors_checker to PIPELINE and CLASS_MAP in main.py.

Five checks implemented

Wildcard originOrigin: https://attacker.comResponse: Access-Control-Allow-Origin: *MEDIUM
Reflected originOrigin: https://attacker.comResponse mirrors the sent origin exactlyHIGH

Credentialed + wildcardOrigin: https://attacker.comACAO: * AND ACAC: trueCRITICAL

Implementation skeleton

class CORSCheckerModule(BaseModule):
    name = "cors_checker"
    description = "CORS Misconfiguration Scanner"
    required_tools = []

    ORIGIN_PROBES = [
        ("reflected",        "https://attacker-reconx.com",          "HIGH"),
        ("null",             "null",                                     "HIGH"),
        ("prefix_bypass",   "https://{domain}.attacker-reconx.com",    "HIGH"),
        ("suffix_bypass",   "https://not{domain}",                      "HIGH"),
    ]

    def _check_url(self, url: str, sess) -> list[dict]:
        findings = []
        domain = urlparse(url).hostname or ""

        for probe_name, origin_tmpl, severity in self.ORIGIN_PROBES:
            origin = origin_tmpl.format(domain=domain)
            resp = self.http_get(
                url, session=sess,
                headers={"Origin": origin},
                timeout=8, verify=False,
            )
            if resp is None:
                continue

            acao = resp.headers.get("access-control-allow-origin", "")
            acac = resp.headers.get("access-control-allow-credentials", "").lower()

            vulnerable = (acao == origin or acao == "null" and origin == "null")
            if not vulnerable:
                continue

            # Escalate if credentials are also allowed
            actual_sev = "CRITICAL" if acac == "true" else severity

            findings.append({
                "url":      url,
                "type":     probe_name,
                "severity": actual_sev,
                "origin_sent": origin,
                "acao":     acao,
                "acac":     acac,
                "poc":      self._poc(url, origin, acac == "true"),
                "confidence": 0.95,
            })

        return findings

    def _poc(self, url: str, origin: str, credentialed: bool) -> str:
        creds = "credentials: 'include'," if credentialed else ""
        return f"""fetch('{url}', {{ {creds} headers: {{Origin: '{origin}'}} }})
  .then(r => r.json()).then(console.log)"""

Output shape must match the standard finding dict so json_report.py picks it up without changes. Add "cors_checker" to the reporting/html_report.py context builder and to the HTML template sidebar.

Module Spec: auth_probe.py §8

Groups with cors_checker in pipeline group 4 (parallel to fuzzer and ssl_checker). Requires pyjwt>=2.8.

Four checks

  • JWT discovery: look for Authorization: Bearer headers or cookies containing base64-encoded JWT structure (xxxxx.yyyyy.zzzzz). Decode without verification. Log alg, exp, iss.
  • alg:none attack: if a JWT endpoint is found, craft a token with "alg":"none" and no signature. Check if the server accepts it (HTTP 200 vs 401).
  • Weak HMAC secret: attempt to verify the JWT signature against a small wordlist (secret, password, 123456, domain name, company name). Use jwt.decode(token, candidate, algorithms=["HS256"]).
  • Cookie flags audit: for all Set-Cookie headers on HTTPS pages, flag missing Secure, missing HttpOnly, missing or permissive SameSite.
import jwt   # pyjwt
import base64, json, re

WEAK_SECRETS = [
    "secret", "password", "123456", "changeme",
    "supersecret", "qwerty", "letmein", "admin",
]

def _analyse_jwt(self, token: str, url: str) -> list[dict]:
    findings = []
    try:
        header = jwt.get_unverified_header(token)
        payload = jwt.decode(token, options={"verify_signature": False})
    except Exception:
        return []

    # Check alg:none
    if header.get("alg", "").lower() == "none":
        findings.append({"type": "jwt_alg_none", "severity": "CRITICAL", "url": url})

    # Brute-force weak secret
    candidates = WEAK_SECRETS + [self.domain, self.target]
    for secret in candidates:
        try:
            jwt.decode(token, secret, algorithms=["HS256", "HS384", "HS512"])
            findings.append({
                "type": "jwt_weak_secret", "severity": "CRITICAL",
                "url": url, "secret": secret,
            })
            break
        except jwt.InvalidSignatureError:
            pass
        except Exception:
            pass

    return findings

Module Spec: sourcemap_analyzer.py §9

Runs in group 5, after fuzzer (which discovers JS URLs). Receives the crawled JS URL list from fuzzer results via _build_kwargs().

Algorithm

  • For each JS URL ending in .js, request URL + ".map" and check the X-SourceMap / SourceMap response headers.
  • Parse the source map JSON: extract sources array (file paths) and sourcesContent array (reconstructed file content).
  • Search each content string for secret patterns (same SECRET_PATTERNS list used in fuzzer.py).
  • Search source paths for interesting indicators: .env, config, credentials, internal, private.
  • Save reconstructed source tree to session/sourcemap_analyzer/reconstructed/.
def _fetch_sourcemap(self, js_url: str, sess) -> dict | None:
    # Check response header first (most reliable)
    resp = self.http_get(js_url, session=sess, timeout=10)
    if resp is None:
        return None
    map_url = (
        resp.headers.get("SourceMap")
        or resp.headers.get("X-SourceMap")
    )
    if not map_url:
        # Fallback: try appending .map
        map_url = js_url + ".map"
        # Also scan last line for //# sourceMappingURL=...
        last_lines = (resp.text or "")[-500:]
        m = re.search(r"sourceMappingURL=(.+)", last_lines)
        if m:
            map_url = urljoin(js_url, m.group(1).strip())

    map_resp = self.http_get(map_url, session=sess, timeout=10)
    if map_resp is None or map_resp.status_code != 200:
        return None
    try:
        return map_resp.json()
    except:
        return None

API methods: SecurityTrails + BinaryEdge §10

Both keys are already configured everywhere except the actual API call methods. Add these to modules/recon.py and register them in _enumerate_subdomains().

# SecurityTrails — subdomain list endpoint
def _api_securitytrails(self) -> list:
    key = self.config.get("api_keys", {}).get("securitytrails", "")
    if not key:
        return []
    data = self._request_json(
        "securitytrails",
        f"https://api.securitytrails.com/v1/domain/{self.domain}/subdomains",
        headers={
            "APIKEY": key,
            "Accept": "application/json",
            "User-Agent": "ReconX/2.0",
        },
        timeout=30,
    )
    if not isinstance(data, dict):
        return []
    return [
        f"{sub}.{self.domain}"
        for sub in data.get("subdomains", [])
        if isinstance(sub, str) and sub
    ]

# BinaryEdge — host search by domain
def _api_binaryedge(self) -> list:
    key = self.config.get("api_keys", {}).get("binaryedge", "")
    if not key:
        return []
    data = self._request_json(
        "binaryedge",
        f"https://api.binaryedge.io/v2/query/domains/subdomain/{self.domain}",
        headers={
            "X-Key": key,
            "User-Agent": "ReconX/2.0",
        },
        params={"page": 1},
        timeout=30,
    )
    if not isinstance(data, dict):
        return []
    return [
        str(e).strip()
        for e in data.get("events", [])
        if isinstance(e, str)
    ]

Module Spec: vhost_enum.py §11

Virtual host enumeration finds applications that share an IP with the main target but are not publicly DNS-resolvable. Runs in group 5, requires ffuf.

class VHostEnumModule(BaseModule):
    name = "vhost_enum"
    description = "Virtual Host Enumeration"
    required_tools = ["ffuf"]

    def run(self) -> dict:
        ips = list({
            self._host_from_url(url)
            for url in self.live_hosts
            if self.is_in_scope(url)
        })
        wl = self._vhost_wordlist()   # SecLists/Discovery/DNS/subdomains-top1million-5000.txt
        found = []

        for ip in ips:
            out = self.module_dir / f"vhost_{ip.replace('.','_')}.json"
            self.exec([
                "ffuf",
                "-u", f"http://{ip}/",
                "-H", f"Host: FUZZ.{self.domain}",
                "-w", wl,
                "-mc", "200,201,204,301,302,307,401,403",
                "-fs", self._baseline_size(ip),  # filter default vhost size
                "-t", "30", "-rate", "50",
                "-of", "json", "-o", str(out), "-s",
            ], timeout=600)

            for r in (self.load_json(out).get("results", []) or []):
                vhost = f"{r['input']['FUZZ']}.{self.domain}"
                found.append({
                    "ip": ip, "vhost": vhost,
                    "status": r.get("status", 0),
                    "size": r.get("length", 0),
                })
                self.warn(f"  VHost found: {vhost} → {ip}")

        return {"found": found, "total": len(found)}

    def _baseline_size(self, ip: str) -> str:
        # Request with a random hostname to get default response size
        resp = self.http_get(
            f"http://{ip}/",
            headers={"Host": f"nxvhost-{random.randint(10000,99999)}.{self.domain}"},
            timeout=8, verify=False,
        )
        return str(len(resp.content)) if resp else "0"

Module Spec: parameter_discovery.py §12

Wraps Arjun and feeds discovered parameters back to the pipeline as additional scan targets. Runs in group 5.

class ParameterDiscoveryModule(BaseModule):
    name = "parameter_discovery"
    description = "Hidden Parameter Discovery (Arjun)"
    required_tools = ["arjun"]

    def run(self) -> dict:
        urls = self._select_targets()   # auth + API endpoints from fuzzer
        if not urls:
            return {"parameters": [], "total": 0}

        url_file = self.module_dir / "arjun_targets.txt"
        out_file  = self.module_dir / "arjun_results.json"
        self.save_text(urls, "arjun_targets.txt")

        self.exec([
            "arjun",
            "-i", str(url_file),
            "-oJ", str(out_file),
            "-t", "10",    # threads
            "-d", "2",      # delay seconds
            "--stable",     # conservative mode
        ], timeout=1200)

        data = self.load_json(out_file)
        params = []
        for url, found in (data if isinstance(data, dict) else {}).items():
            for param in (found or []):
                params.append({"url": url, "param": param})
                self.warn(f"  Parameter found: {url}?{param}=...")

        return {"parameters": params, "total": len(params)}

    def _select_targets(self) -> list[str]:
        # Pull auth + API endpoints from fuzzer classified output
        classified = self.fuzzer_results.get("classified", {})
        candidates = set()
        for category in ("auth", "api", "with_params"):
            candidates.update(classified.get(category, []))
        return self.filter_in_scope_urls(candidates)[:150]

Open questions §16

1. Should AI advisor block or run in background?

The background thread approach means Telegram gets the advice 20–60 seconds after the module finishes, while the next module group is already running. This is the right default for speed. However if someone wants to review AI advice before proceeding (e.g. to manually adjust scope), a --ai-wait flag that blocks until advice is sent would be useful. Recommend: background by default, opt-in blocking.

2. SecurityTrails and BinaryEdge — free tiers have rate limits

SecurityTrails free tier: 50 requests/month. BinaryEdge free tier: 250 credits/month. Both should be gated behind use_securitytrails: true / use_binaryedge: true flags that default to false in config.yaml, unlike the other passive sources which default to true. This prevents accidental quota burn.

3. arjun install method

Arjun is a pip package. It should go in requirements.txt and be installed inside the venv, not system-wide. However it also installs a CLI binary. Verify that the venv bin path is in PATH during subprocess calls, or use python -m arjun as the command instead of bare arjun.
